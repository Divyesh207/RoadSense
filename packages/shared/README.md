# Shared Package

This package contains shared constants, type definitions, and contract schemas shared across services and clients.

## Core Enums

- **Damage Types**: `POTHOLE`, `CRACK`, `DEPRESSION`, `WATERLOGGING`, `SURFACE_DAMAGE`, `OTHER`
- **Severity Levels**: `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`
- **Inspection Statuses**: `DRAFT`, `SUBMITTED`, `UPLOADING`, `PROCESSING`, `ANALYZED`, `REVIEW_REQUIRED`, `REVIEWED`, `COMPLETED`
- **Maintenance Statuses**: `OPEN`, `ASSIGNED`, `IN_PROGRESS`, `COMPLETED`, `VERIFICATION_PENDING`, `VERIFIED`, `REJECTED`, `CANCELLED`
- **User Roles**: `ADMIN`, `ROAD_AUTHORITY`, `FIELD_INSPECTOR`, `MAINTENANCE_CONTRACTOR`
